
# Fatema Begum | Developer Portfolio

A responsive personal portfolio website showcasing my background,
technical skills, and projects as a Software Engineering student
at Noakhali Science and Technology University , Bangladesh.

## About

I am learning software development through hands-on projects,
programming practice, and continuous improvement.

My interests include frontend development, problem solving,
and building useful software applications.

## Features

- Responsive mobile-first layout
- Dark and light theme toggle
- Mobile navigation menu
- Smooth scrolling
- Skills and project showcase
- GitHub and LinkedIn links

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- CSS Grid and Flexbox
- Git and GitHub
- GitHub Pages

## Run Locally

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser, or use Live Server.
